# قناص — Qannas

تطبيق Android بالعربية لقراءة عروض الرحلات في التطبيقات المدعومة ومقارنتها بمرشحات السائق، مع إدارة الحسابات والتراخيص في Supabase ولوحة إدارة ويب مضمنة.

> **حالة المنتج:** تحت التطوير. نجاح الاختبارات أو بناء APK لا يعني اعتماد التطبيق للإنتاج أو قبول نشره في Google Play. يلزم تشغيل ترحيلات قاعدة البيانات، إعداد الخدمة والتوقيع، واختبارات جهاز وتكامل موثقة قبل الإصدار.

## البنية

- `core/`: تحليل نصوص وشجرة العرض، ملفات التطبيقات، تقييم المرشحات والمناطق، ومنع تكرار النقر. Kotlin/JVM، قابل للاختبار دون جهاز.
- `app/`: Android/Jetpack Compose، المصادقة والتفعيل، إعدادات المرشحات، الإتاحة، وخدمة إشعار أمامية.
- `supabase/migrations/`: مخطط قاعدة البيانات، RLS، RPCs، وتسجيل ملفات السائقين. الترحيلات الجديدة تراكمية؛ لا تُعدّل ترحيلًا نُفذ سابقًا.
- `supabase/tests/`: اختبارات PostgreSQL مع أدوار Auth محاكية؛ ليست بديلًا لاختبار Supabase الحقيقي.
- `admin/`: لوحة ويب بواجهة عربية وتفويض خادمي وجلسة ذاكرية مؤقتة.
- `app/src/main/assets/admin/`: نسخة مطابقة من لوحة الإدارة؛ يثبت اختبار Node التطابق.
- `.github/workflows/build-apk.yml`: اختبارات PR وبناء debug، وإصدار موقّع منفصل عن أسرار PR.

## البناء والتحقق

المتطلبات: JDK 17، Android SDK 36، Node.js 20+ لاختبار لوحة الإدارة.

```bash
./gradlew --no-daemon :core:test :app:testDebugUnitTest :app:lint :app:assembleDebug
node --test admin/tests/admin-static.test.mjs
```

مسار debug APK: `app/build/outputs/apk/debug/app-debug.apk`.

بدون إعدادات `SUPABASE_URL` و`SUPABASE_ANON_KEY`، يمكن اختبار البناء، لكن تسجيل الدخول الحي لا يعمل. مفتاح الواجهة العام ليس حاجز الأمان؛ الحماية الملزمة على الخادم هي RLS/RPC.

راجع [دليل الإعداد](docs/SETUP.md) و[بوابات الإطلاق واختبارات القبول](docs/PRODUCTION_READINESS.md).

## مبادئ التشغيل الآمن

1. لا يعمل الالتقاط إلا بعد مصادقة وترخيص صالح وإذن الإشعارات وإمكانية الوصول وموافقة المستخدم الصريحة.
2. يُقرأ الترخيص في الذاكرة قبل الإيماءة، وتُعاد مراجعته دوريًا أثناء تشغيل الخدمة. لا تُحفظ رموز الجلسة على القرص، ويظل التشغيل معطلًا بعد موت العملية أو إعادة الإقلاع حتى الدخول مجددًا.
3. البيانات غير المقروءة والمرشحات المعيبة وشاشات التأكيد والحزم غير المدعومة لا تؤدي إلى قبول عرض.
4. لا يُرفع محتوى الشاشة أو السعر أو الإحداثيات في مسار الالتقاط الحالي. راجع أي ميزة معايرة مستقبلية قبل تفعيل رفع البيانات.
5. لا توضع مفاتيح `service_role` أو مفاتيح توقيع أو أسرار خادم في التطبيق أو الويب أو المستودع.
6. التطابق التقني مع إصدار تطبيق رحلة لا يثبت السماح التعاقدي بالأتمتة؛ يلزم التحقق من الشروط وسياسات المتجر قبل الإطلاق.
