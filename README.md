# سبّاق — Sabbaq

تطبيق Android عربي موجّه مبدئيًا للسوق السعودي لقراءة عروض الرحلات في التطبيقات المدعومة ومقارنتها **بقواعد ثابتة يحددها السائق**، مع إدارة الحسابات والتجارب والتراخيص في Supabase ولوحة إدارة ويب مضمنة. الواجهة مبنية فعليًا بـJetpack Compose، وتضم تعريفًا أوليًا، ولوحة قيادة، ومرشحات متقدمة، ومعاينة محلية لقرار القبول، وحسابًا واشتراكًا.

> **حالة المنتج:** تحت التطوير والاعتماد. بناء APK أو نجاح اختبار لا يثبت جاهزية إنتاجية شاملة أو قبول Google Play. لا يتم نشر التطبيق أو ترحيل قاعدة إنتاج أو شراء خدمة ضمن هذا العمل.

## نسختا التوزيع

| النسخة | المسار التجاري | الحدود |
|---|---|---|
| `direct` | APK وأكواد الإدارة، مع سعر ومدة من الخادم | السعر المرجعي الأولي18.75 ريال لكل30 يومًا، قابل للتعديل. لا دفع تلقائي ولا تجديد تلقائي بكود التفعيل. |
| `play` | نسخة منفصلة بلا بيع خارجي أو دعوات شراء أكواد الإدارة | لا تُعرض أسعار قاعدة التطبيق كأنها أسعار Google Play Billing. دفع المتجر ومنتجاته لم تُفعّل؛ يلزم اعتماد سياسات المتجر وإعداداته قبل النشر. |

النسختان تستعملان هوية حزمة التطبيق نفسها، فلا تُثبتان جنبًا إلى جنب. يجب الحفاظ على هوية التوقيع والإصدار أثناء الانتقال بين قنوات التوزيع؛ اختلاف التوقيع أو معرّف الجهاز الذي يعيده Android قد يستلزم معالجة إدارية للربط، ولا يُعاد منح تجربة لمجرد تغيير النسخة.

## البنية

`core/` يضم التحليل وتقييم المرشحات ومنع تكرار النقر في Kotlin/JVM. `app/` يضم Compose والمصادقة والإتاحة وخدمة الإشعار، و`supabase/migrations/` يضم الترحيلات التراكمية وRLS وRPCs. الإدارة داخل التطبيق شاشة Compose أصلية في `app/src/main/java/app/sabbaq/ui/admin/` (نسخة direct فقط) تستعمل جلسة التطبيق نفسها؛ ولوحة الويب في `admin/` للحاسوب فقط ويختبرها Node. `scripts/android_ui_smoke.py` يفتح الشاشات الأصلية ويلتقطها على محاكي مكتمل، دون حساب حي أو تشغيل خدمات.

## البناء والتحقق

المتطلبات: JDK17 وAndroid SDK36 وNode.js20+ وPostgreSQL للاختبارات الخادمية.

```bash
./gradlew --no-daemon :core:test :app:testDirectDebugUnitTest :app:testPlayDebugUnitTest :app:lint :app:assembleDirectDebug :app:assemblePlayDebug
node --test admin/tests/admin-static.test.mjs
```

ملفا debug الناتجان في `app/build/outputs/apk/direct/debug/app-direct-debug.apk` و`app/build/outputs/apk/play/debug/app-play-debug.apk`. نشاط المعاينة في source set debug فقط، ولا يمنح مصادقة أو ترخيصًا ويغيب عن release.

الدخول الحقيقي يحتاج عنوان Supabase ومفتاح العميل العام، وترحيلات الخادم، وتفعيل Google معWeb client ID مطابق، وتفعيل مزود SMS فيSupabase. لم تُستخدم حساباتGoogle أو أرقام حية في الاختبارات المحلية. بيانات OAuth/OTP أو روابط الخدمة الناقصة لا تُستبدل بنجاح وهمي.

إعدادات العميل العامة للمشروع الذي حدده المالك محفوظة في `config/public-backend.properties`. تُدرج في الحزمة؛ لها أولوية أقل من متغيرات البيئة و`local.properties`. المفتاح publishable عام، لا مفتاح إدارة أو بديلًا عن RLS. فحص 19 أكتوبر 2026 أكد اتصال Auth و`public_offer` برمز200 بعد تطبيق ترحيلات002–004 على المخطط الموجود عبر صلاحية إدارة مخوّلة. منذ 20 أكتوبر 2026 مزود Google منشور للإنتاج بعميل Android لشهادة الإصدار، ومزود Phone مفعّل عبر Twilio Verify، وترحيل `0005` (حذف الحساب) مطبّق؛ راجع [تقرير إصدار 1.3.0](docs/RELEASE_1.3.0_2026-10-20.md). سياسة الخصوصية وصفحة حذف الحساب منشورتان على https://yahooyahoo99.github.io/ ومربوطتان داخل التطبيق.

## مبادئ التشغيل

الالتقاط لا يعمل إلا بعد مصادقة وترخيص وإشعارات وإتاحة وتفعيل صريح، بالإضافة إلى موافقة منفصلة على إفصاح استخدام الإتاحة. تُراجع الموافقة والترخيص مباشرة قبل الإيماءة، وتُراقب الصلاحية أثناء الخدمة. رموز الدخول والتراخيص قصيرة الأجل ذاكرية؛ موت العملية أو الإقلاع لا يعيدان صلاحية التشغيل تلقائيًا.

التجربة يمنحها الخادم بفعل واضح، افتراضيًا3 أيام، مع سجل يمنع إعادة منحها للحساب. تعطيلها إداريًا لا يوقف الاشتراك المدفوع. حماية تكرار التجربة بمُعرّف جهاز يبلغه العميل لا تعادل إثباتًا عتاديًا أو Play Integrity. لا تُرفع نصوص العروض أو السعر أو الإحداثيات في مسار الالتقاط الحالي؛ أي ميزة معايرة مستقبلية تحتاج مراجعة إفصاح وخصوصية مستقلة.

لا توضع مفاتيح `service_role` أو التوقيع في التطبيق أو لوحة الويب أو المستودع. شروط منصات الرحلات والخصوصية وإقرارات الإتاحة والخدمة الأمامية وسياساتGoogle Play بوابات مستقلة لا يثبتها نجاح التجميع. راجع [دليل الإعداد](docs/SETUP.md)، [نظام التصميم](docs/DESIGN_SYSTEM.md)، و[بوابات الإطلاق](docs/PRODUCTION_READINESS.md).
